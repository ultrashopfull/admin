CAMBIOS EN LA SECCION USUARIOS (vendedores)
============================================

1. Que se corrigio en el codigo
- El backend (Edge Function admin) ya permite el acceso de vendedores para
  staff_login, panel_sync, panel_operation, profile.save y client.* licenciados.
  Antes rechazaba a todo no-admin con "Se requiere rol admin".
- Las contrasenas creadas desde ahora se guardan tambien en password_text y se
  muestran/copian solo para administradores (ojo + copiar en la tabla).
- El snapshot del panel se filtra por licencias del vendedor: solo ve sus
  licencias, cuentas, suscripciones, clientes, trabajos y su propio usuario.
- El login devuelve rol, nombre completo, licencias (nombres mostrables) y
  estado activo; los usuarios suspendidos no pueden entrar.
- El panel cliente recuerda la contrasena del vendedor/admin en memoria y
  la recupera tras sincronizar, por eso el ojo/copy sigue funcionando.
- Se agrego el ojo en el campo Contrasena del modal de usuario.

B. Edge Function admin:

3. Contraseñas anteriores
Las contrasenas creadas antes de esta actualizacion no se pueden recuperar
(estan guardadas solo como hash). Para ver/copiar la contrasena de un usuario
antiguo, edita el usuario y escribe una nueva contrasena; desde entonces
aparecera con el ojo y el boton copiar.
